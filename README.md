# matthewkim-portfolio

Personal portfolio website showcasing Matthew Kim's projects, academics, and skills.

## Run Locally

This version is a static site with no build step.

1. Open `index.html` directly in a browser, or
2. Serve the folder with any static server (example: `python3 -m http.server 8080`).

## Structure

- `index.html`: page content and section layout
- `styles.css`: visual design system and responsive styling
- `script.js`: section reveal transitions and active nav tracking
- `assets/Matthew-Kim-Software-Engineer.pdf`: downloadable resume
